# Troubleshoot step by step

1. Get the exact symptom: the full error text, what changed recently, when it started, whether it
   happens every time. Ask for a screenshot or the log lines if you do not have them.
2. List the two or three most likely causes, most likely first, each with how to confirm or rule it out.
3. Give one test or change at a time, the cheapest and safest first, and say what each result would
   mean. Wait for the result before the next step.
4. Before anything that deletes data, reinstalls, changes firmware or registry settings, or cannot be
   undone, say so and give the way back (a backup, a restore point, the old value).
5. When it is fixed, say what the cause was in one line, so it can be recognised next time.
6. If the cause was not obvious, offer to save the fix as a skill draft (see "Remember and improve").
